Assignement : How to use H2 Database in Spring Boot

-----------------------------------------------------------------------------------------------

1) Create Spring Starter Project with below dependencies

	a) spring-boot-starter-web
	b) spring-boot-starter-data-jpa
	c) H2 (embedded database)
	d) Project Lombok
	e) spring-boot-devtools

2) Configure properties in application.properties file

	a) datasource
	b) server.port  (if required)

#datasource properties for H2 DB
spring.datasource.url=jdbc:h2:mem:testdb
spring.datasource.username=sa
spring.datasource.password=sa
spring.datasource.driver-class-name=org.h2.Driver

#server port
server.port=9090

Note: We can access H2 DB from browser using below URL

		URL : http://localhost:9090/h2-console

Note: By default we will get tomcat with 8080. If it is already using by other service then we have to change the port.

3) Create Entity class and map with DB table using JPA annotations

	a) @Entity
	b) @Table
	c) @Id
	d) @GeneratedValue
	e) @Column

4) Create Repository interface by extending JpaRepository (to perform Crud operations)

Note: We no need to implement this interface. Data Jpa will implement our interface in runtime using proxy design pattern. @Repository annotation is optional.

5) Create Service interface with business methods and impement them using Impl class

6) Create RestController class with methods to handle request & response

7) Run the application and test it using PostMan

8) Push the project into Git Hub Repository

9) Deploy the project into HEROKU Cloud
